# Umangly – AI Powered Mental Health & Wellness App

Umangly is an AI-powered mental health and wellness mobile application designed to help users improve emotional well-being through mood tracking, AI conversations, meditation, and behavioral analytics. It acts as a personal digital companion for mental wellness, combining multiple features into one unified platform.

---

##  Features

###  Mental Wellness Core
- Daily Mood Tracking with analytics
- AI-based emotional insights
- AI-powered Diary (Journal) with smart suggestions

###  AI Virtual Companions
- **Meera** – Empathetic AI (Gemini-powered)
- **Arav** – Motivational AI (Dialogflow CX)
- Real-time conversational emotional support

###  Mindfulness & Relaxation
- Guided Meditation Sessions
- Breathing Exercises (4-4-7, 4-2-4, etc.)
- Healing Frequencies & Ambient Sounds
- Daily Affirmations

###  Emotion Detection & Gamification
- Real-time Smile Detection (OpenCV)
- Streak System & Reward Points
- Engagement tracking for consistency

###  Analytics Dashboard
- Weekly & Monthly Mood Analysis
- AI-generated behavioral insights
- Activity & streak tracking

---

##  Tech Stack

###  Frontend
- Flutter (Cross-platform)
- Dart
- Material Design 3

### Backend & Cloud
- Firebase Authentication
- Cloud Firestore (NoSQL DB)
- Firebase Storage
- Firebase Analytics

### AI & ML
- Google Gemini AI (Conversational AI)
- Dialogflow CX (Intent-based chatbot)
- OpenCV (Emotion Detection)

### Tools & Libraries
- audioplayers (audio streaming)
- flutter_tts (text-to-speech)
- video_player
- provider (state management)

---

## 📂Project Architecture

The app follows a client-cloud architecture:

```text
Flutter App (Frontend)
        ↓
Application Logic Layer
        ↓
Firebase Backend (Auth, Firestore, Storage)
        ↓
AI Layer (Gemini + Dialogflow CX)
        ↓
Emotion Detection API (OpenCV)
```
